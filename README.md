# Stacks and Queues: Array vs Linked List

## Description

This project implements:

1. ArrayStack
2. LinkedStack
3. ArrayQueue (Circular Queue)
4. LinkedQueue

Additional applications:

- Parentheses Balance Checker
- Print Queue Simulation

## Files

- array_stack.py
- linked_stack.py
- array_queue.py
- linked_queue.py
- balance_checker.py
- print_queue.py
- main.py
- analysis.md
- README.md

## Running the Program

```bash
python main.py
```

## Features

### Array Stack
- Push
- Pop
- Peek
- is_empty
- is_full

### Linked Stack
- Push
- Pop
- Peek
- is_empty

### Circular Array Queue
- Enqueue
- Dequeue
- Peek Front
- Wrap-around support

### Linked Queue
- Enqueue
- Dequeue
- Peek Front

## Error Handling

The program raises descriptive exceptions for:

- Stack Overflow
- Stack Underflow
- Queue Overflow
- Queue Underflow
